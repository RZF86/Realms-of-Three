# Action Game - Character Selection

A fun action game where you can choose your character and battle enemies!

## Features

- **Character Selection**: Choose between Human, Frog, or Dragon
- **Action-Based Combat**: Real-time gameplay mechanics
- **Character-Specific Abilities**: Each character has unique skills and attacks

## Characters

### Human
- **Speed**: Medium
- **Strength**: Medium
- **Special Ability**: Tactical strikes and sword combat

### Frog
- **Speed**: High
- **Strength**: Low
- **Special Ability**: Jumping and agility-based attacks

### Dragon
- **Speed**: Low
- **Strength**: High
- **Special Ability**: Fire breath and powerful melee attacks

## Requirements

- Python 3.8+
- pygame (for rendering and game loop)

## Installation

```bash
# Clone the repository
git clone https://github.com/RZF86/game-1.git
cd game-1

# Create virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

## Running the Game

```bash
python main.py
```
